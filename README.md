# Brava Home Care

Website for [bravahomecare.es](https://bravahomecare.es), a home care service for second homes in Roses and the Costa Brava.

Static site, no build step. Available in Spanish, Catalan, English and French (`es/`, `ca/`, `en/`, `fr/`).

## Run locally

```sh
python3 -m http.server --directory .
```

Then open http://localhost:8000/.

## Deployment

Hosted on GitHub Pages from the `main` branch.
